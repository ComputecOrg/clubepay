# Como Usar Pix Recorrente para Fidelizar Clientes

Pix revolucionou pagamentos instantâneos no Brasil. Agora, com **Pix recorrente**, você pode criar assinaturas de forma simples e segura.

## Por Que Pix Recorrente?

### Para Donos de Negócio
- ✅ Recebimento automático (sem gesto manual do cliente)
- ✅ Baixa taxa (2-3% via Asaas)
- ✅ Sem cartão de crédito (muitos clientes preferem)
- ✅ Cobrança pode ser diária, semanal ou mensal

### Para Clientes
- ✅ Fácil de autorizar (QR Code + senha)
- ✅ Seguro (Banco do Brasil garante)
- ✅ Sem dados de cartão na internet
- ✅ Cancela quando quiser

---

## Diferença: Pix vs Cartão de Crédito

| Aspecto | Pix Recorrente | Cartão de Crédito |
|--------|----------------|------------------|
| Taxa | 2-3% | 2.99% |
| Segurança | Alta (intermediário = Banco) | Depende do processador |
| Cancelamento | Imediato | 1-2 dias |
| Rejeição | Rara | Comum (limite, vencimento) |
| Cliente Prefere | Sim (privacidade) | Às vezes |

## Como Implementar no ClubePay

### Passo 1: Crie Conta no Asaas
Asaas é o provedor Pix recorrente mais usado no Brasil.

```
1. Acesse asaas.com
2. Cadastre negócio
3. Gere chave PIX
4. Vincule no ClubePay
```

### Passo 2: Configure Plano de Assinatura
No ClubePay, crie um plano com:
- Nome: "Café Premium - Pix Recorrente"
- Valor: R$ 99/mês
- Recorrência: Mensal
- Tipo de cobrança: Pix

### Passo 3: Cliente Assina
Cliente:
1. Acessa seu link de checkout
2. Escaneia QR Code do Pix recorrente
3. Confirma na app do banco
4. Pronto! Cobrança automática começa

### Passo 4: Monitore
- Dashboard do ClubePay mostra todos os assinantes
- Alertas de rejeição
- Relatórios de receita

## Estratégia de Fidelização

### Problema
70% dos assinantes cancelam no 1º mês.

### Solução
1. **Comunicação**: Email todo dia 5 do mês informando cobrança
2. **Valor**: Garanta que cliente vê valor (promoções exclusivas)
3. **Suporte**: Atenda WhatsApp em 2 horas
4. **Upgrade**: Ofereça plano premium após 3 meses

## Casos de Sucesso

### Cafeteria Vila Mariana (São Paulo)
- **Antes**: 5 clientes/dia, sem recorrência
- **Depois**: 50 assinantes Pix, R$ 4.950/mês recorrente
- **Tempo**: 2 meses para atingir esse número

**Dica deles**: Oferecer primeira semana grátis aumentou conversão em 300%.

## Dúvidas Comuns

### P: Quanto tempo leva pra receber o Pix?
**R:** 1-2 minutos. Asaas transfere direto pra sua conta.

### P: E se o cliente não tiver saldo?
**R:** Cobrança é rejeitada. ClubePay envia email ao cliente. Retry automático em 3 dias.

### P: Posso cancelar assinatura?
**R:** Sim, pelo dashboard. Cliente também cancela pelo link de desinscrição.

### P: Taxa do Pix recorrente é igual ao normal?
**R:** Não. Pix recorrente custa 2% (normal é 0%). Mas vale pelo churn reduzido.
